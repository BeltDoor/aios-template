# Recipes

Saved workflows you can run again. We start adding these in Level 3.

A recipe is just a saved set of instructions for something you do over and over. Examples:

- *Pre-call prep* — pull the client's recent emails + calendar context + last meeting notes into a 1-page brief
- *Weekly Friday update* — write the weekly recap to your retainer client from this week's notes
- *Discovery follow-up* — turn a discovery call recording into a personalized follow-up email + proposal outline

Once a recipe is built, you run it by typing its name. It's the same every time.
